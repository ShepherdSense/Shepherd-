SHEPHERD FIELD KIT
=================
1. Double-click INSTALL_SHEPHERD.bat to install the latest Shepherd
   on this Windows PC (builds from source, creates desktop shortcut).
2. Plug in an ESP32 and double-click FLASH_NODE.bat to flash the
   Shepherd Node sensor firmware.

Windows blocks true USB auto-run, so the double-click IS the install.
See README.md (one folder up) for details and honest notes.
